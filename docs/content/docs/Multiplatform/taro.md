## 简介

[Taro](https://taro.jd.com/) 是京东开源的开放式跨端跨框架解决方案，支持使用 React/Vue 等框架开发微信、支付宝、抖音等各平台小程序、H5 与 React Native 应用。

## 能力

- 一套代码编译到各平台小程序、H5、RN
- 支持 React、Vue2/Vue3、Preact 等框架
- 内置路由、状态管理、多端组件库（NutUI）适配

## 使用方法

初始化项目：

```bash
npx @tarojs/cli init myApp
```

编译到微信小程序：

```bash
npm run dev:weapp
```

编译到 H5：

```bash
npm run dev:h5
```
